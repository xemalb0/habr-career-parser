# Habr Career Parser

An interactive CLI Python web scraper for monitoring the tech job market on Habr Career (https://habr.com).

## Features & Tech Stack
* Asynchronous requests (`aiohttp`)
* Parsing (`BeautifulSoup4`)
* Excel export (`pandas`, `openpyxl`)

## Installation & Usage
```bash
git clone https://github.com
cd habr-career-parser
pip install -r requirements.txt
python main.py
```
